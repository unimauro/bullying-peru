### F-14 · Carga del índice: sin precarga en focus, estado de carga real, progreso

```js
// app.js:583  — eliminar la precarga en focus
// input.addEventListener("focus", () => { ensureSchoolsIndex()... }, { once: true });

// app.js:245 — progreso + estado ocupado
async function ensureSchoolsIndex() {
  if (schoolsIdx) return schoolsIdx;
  if (!schoolsIdxPromise) {
    const st = document.getElementById("school-status"), tb = document.getElementById("school-results");
    const panel = document.querySelector(".school-panel");
    panel.setAttribute("aria-busy", "true");
    panel.querySelectorAll("select").forEach(s => s.disabled = true);
    tb.innerHTML = '<tr><td colspan="9" class="loading">Descargando la lista nacional de colegios (≈ 1 MB, solo la primera vez)… <progress id="idx-prog" max="100" value="0"></progress></td></tr>';
    schoolsIdxPromise = fetch(C.data.schoolsIndex).then(async r => {
      const total = +r.headers.get("content-length") || 0, reader = r.body.getReader(); let got = 0, chunks = [];
      for (;;) { const { done, value } = await reader.read(); if (done) break; chunks.push(value); got += value.length;
        const p = document.getElementById("idx-prog"); if (p && total) p.value = Math.round(got / total * 100); }
      const txt = new TextDecoder().decode(await new Blob(chunks).arrayBuffer());
      schoolsIdx = JSON.parse(txt); return schoolsIdx;
    }).catch(() => { schoolsIdx = []; if (st) st.textContent = "No se pudo descargar la lista. Revisa tu conexión y vuelve a intentar."; return schoolsIdx; })
      .finally(() => { panel.removeAttribute("aria-busy"); panel.querySelectorAll("select").forEach(s => s.disabled = s.id === "sf-distrito" && !sf.region); });
  }
  return schoolsIdxPromise;
}
```

## Los 5 cambios de mayor impacto (en orden)

1. **Reordenar la página para las familias (#1, #16, #23).** Familias → buscador → cifras; correlación y pensiones al final; un solo aviso corto de "no es ranking"; 2 CTAs en el hero (SíseVe y `tel:100`). Es el cambio que convierte un observatorio de datos en la herramienta que dice ser; sin él, en móvil la ayuda está 7 000 px abajo.
2. **Arreglar el buscador para nombres numéricos (#3) y la carga del índice (#14).** Hoy la mitad de los colegios públicos no se encuentra por su nombre, y quien filtra por región descarga 4,5 MB sin señal de progreso. Son dos líneas de JS + un estado de carga honesto; el sharding por región puede venir después.
3. **Contenido cortado e inalcanzable en móvil (#2, #7, #9).** `minmax(0,1fr)` en `.grid-2`, selectores de hijo directo en `.school-table`, ocultar `.kpi .tag` en móvil. Tres fixes CSS de una línea que hoy esconden columnas, desglose por tipo y etiquetas.
4. **Contraste de la acción principal y FAB (#5, #6).** Naranja `#c2410c` para superficies con texto y FAB circular de 56 px que se oculta al abrir el chat. Afecta al botón más importante del sitio y a todo lo que el FAB tapa.
5. **Mapa usable en móvil y coherente (#8, #12, #13, #4).** Corregir `default_year` (hoy el selector dice 2026 y dibuja 2024), sacar leyenda/control del lienzo en ≤ 640 px, popup en táctil con la cifra antes de bajar a distritos, y no mostrar el mapa de sedes mientras `schools_geo.json` no exista.
